# SkillPassport

**Skills You Can Prove.**

SkillPassport is an AI-assisted skill intelligence platform that connects students' real project work to evidence-backed skills, identifies gaps against a target role, and recommends personalized learning paths.

## Problem

Resumes often list skills without demonstrating them. Relevant evidence is scattered across repositories, project documents, portfolios, and certificates, making it difficult for recruiters to assess abilities and for students to identify skill gaps.

## Solution

SkillPassport analyses project evidence to create a structured skill profile, explains role matches, and recommends actionable learning paths. Every skill claim is linked to supporting evidence, and unsupported claims are never presented as verified.

## Core Features

- **Evidence-Based Skills** — Link skills to relevant projects, files, or code snippets.
- **Skill Profiling** — Organize identified skills and their evidence.
- **Role Matching** — Compare a profile against target role requirements.
- **Gap Analysis** — Identify missing skills and areas needing stronger evidence.
- **Learning Roadmap** — Recommend learning priorities based on identified gaps.
- **Recruiter View** — Present a concise, shareable skill profile.

## Getting Started

### Prerequisites

- Node.js and npm
- Git

### Installation

```bash
git clone https://github.com/rajrasane/IEEE-Synapse-Vyoma-Elite.git
cd skill-passport
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Responsible AI

SkillPassport distinguishes between evidence found and skills independently verified. Project descriptions and AI-generated inferences alone do not establish proficiency. Recommendations should be explainable, reviewable, and linked to their supporting evidence.
